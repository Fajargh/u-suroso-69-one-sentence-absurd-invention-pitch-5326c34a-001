## The pitch

> My toaster ejects burnt bread with a tiny parachute, so breakfast floats gently to the counter instead of setting off the smoke alarm every morning.

## How it works

Run `main.py` and it writes the single-sentence pitch to `/output/entry.txt`, after validating it: 1–220 characters, non-blank, exactly one sentence.

```sh
python3 main.py
cat /output/entry.txt
```
